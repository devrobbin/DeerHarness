# ADR-0001 · 产品定位

| 项 | 值 |
|---|---|
| **状态** | 已采纳（2026-09-10） |
| **影响文档** | [01-愿景与定位](../01-vision.md) |

## 背景

项目融合 PenguinHarness（Agent 工厂）与 DeerFlow（运行时）。需明确：DeerHarness 是"缝合层"还是独立产品层，差异化护城河在哪里。

## 决策

**DeerHarness 定位为"以 Agent 团队为单位的本地优先协同进化平台"**——不是两个开源项目的门户聚合，而是它们的**编排 + 进化控制面**。核心差异化是**团队级协同进化 + 团队模板业务资产**，两个上游都没有这一层。

## 后果

- 产品叙事以"团队"为产品单位，而非单 Agent。
- 团队模板（跨境电商 5 套）成为产品资产，需持续扩充。
- 上游演进（penguin Machines、deerflow 2.X harness）作为能力接入而非定位变更。
