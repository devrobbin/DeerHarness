# ADR-0006 · 团队模板资产

| 项 | 值 |
|---|---|
| **状态** | 已采纳（2026-09-10） |
| **影响文档** | [06-团队模板](../06-team-templates.md) |

## 背景

多智能体编排需要"团队"这一组织单位，但上游都没有团队级模板资产。需定义团队模板模型，让"一支运营团队怎么组织、怎么干活"可固化、可复用。

## 决策

**团队模板 = soul（主代理人设）+ members（成员清单）+ workflows（预设工作流）三要素**，内置 5 个跨境电商团队模板（跨境总监 / Amazon 专项 / TikTok Shop / 内容工厂 / 履约财税）。

- 主代理（orchestrator）用 `task` 工具按名分派成员（可并行），汇总结果。
- 成员写入 DeerFlow 2.X `subagents.custom_agents`。
- 进化产物（soul / member_prompt / workflow_task 覆盖）运行时合并进模板基础值。

## 后果

- 团队模板成为产品差异化业务资产。
- 后续演进：模板序列化导入/导出、跨平台团队扩充、团队专属评测用例补全。
