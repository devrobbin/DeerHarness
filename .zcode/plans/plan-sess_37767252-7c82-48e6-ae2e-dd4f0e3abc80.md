# 提案: Agent 装备中心(一期全量)

## 背景事实(调研结论)
- **模型**:penguin 原生不支持每 agent 模型 —— config 只有运行参数,模型是项目级默认 + 会话创建时选(POST /sessions {modelId, provider})。这就是"不能切模型"的根因
- **agency-swarm**:Agent = 角色 + 人设 + 每 agent 工具集 + 参数;GUI 结构化创建。本期只借鉴"结构化表单"模式,不做 OpenAPI 工具生成与通信流可视化
- **per-agent 维护**:penguin 原生契约齐全 —— toolsBuiltin(整表替换)、mcpServers({name, config} 存储)、技能库(安装/卸载/zip)、Vault(整表替换,掩码)

## 一、模型切换(偏好层实现)
- 新增 `gateway/agent_prefs.py`:JSON 存储 agent_id → {provider, model_id}(gateway/config/agent_prefs.json)
- `GET/PUT /api/agents/{id}/model-pref`;`GET /api/agents/models` 代理项目模型列表(含 default 标记)
- **改造 `/api/agents/{id}/chat`**:创建会话时若有偏好 → POST sessions body 带 {modelId, provider};无偏好不传(penguin 回落项目默认)
- 效果:Chat 页 Agent 模式、Studio AgentChat 全部自动生效,前端可切换每 agent 默认模型

## 二、AgentSettings 抽屉 → 7 Tab(移植 penguin 7-tab 的有用项)
| Tab | 内容 | 端点 |
|---|---|---|
| 📋 定义 | 名称/描述(现有) | PUT config |
| 🧠 人设 | systemPrompt(现有)+ 占位符 chips 插入 {{AGENTS_MD}}/{{VAULT_KEYS}}/{{SKILL_METADATA}} | PUT config |
| 🎯 模型 | 项目模型下拉 + "默认(项目)" + 运行参数(现有) | model-pref / config |
| 🔧 工具 | toolsBuiltin 表格:名称只读/权限 r\|rw/超时/输出上限/call_description 开关,整表保存 | PUT config toolsBuiltin |
| 🔌 MCP | per-agent MCP:name + stdio(command+args+env)/sse(url) + enabled,序列化为 penguin {name, config} | PUT config mcpServers |
| 🧩 技能 | 技能库浏览(分组)+ 安装/卸载 + 已装列表(版本) | /skills* 代理端点 |
| 🔐 Vault | key/value 表,value 掩码,整表保存 | vault 代理端点 |

## 三、AgentBuilder 双模式
- 保留"一句话造 Agent"(自然语言)
- 新增"📝 结构化创建":agent_id/名称/描述/人设/模型偏好/默认工具勾选(9 个 builtin)/初始技能勾选 → 创建后自动打开设置抽屉继续配置

## 四、后端新增代理端点(gateway/routes/agents.py)
- model-pref GET/PUT、models 列表、skills-library/install/uninstall、vault GET/PUT
- AgentConfigUpdate 扩展 tools_builtin / mcp_servers(透传 penguin 契约)
- chat 会话创建带模型偏好
